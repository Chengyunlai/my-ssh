# 架构决策记录（ADR）

跨三个以上模块、改变进程边界或引入长期约束的决定，应在本目录新增 ADR。文件命名：
`NNNN-short-title.md`，编号递增。已接受的 ADR 不直接改写结论；方向变化时新增 ADR 并标记替代关系。

## 模板

```markdown
# NNNN：决策标题

- 状态：提议 / 接受 / 已替代
- 日期：YYYY-MM-DD
- 相关 Issue：#123

## 背景

要解决的问题、约束和已有证据。

## 决定

采用的方案与明确边界。

## 后果

收益、代价、风险与后续工作。

## 备选方案

考虑过但未采用的方案及原因。
```
