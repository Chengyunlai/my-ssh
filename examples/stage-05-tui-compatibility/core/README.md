# 规则归属与断点

- `validateTuiPlugin`：纯数据公开合同，先验证 ID、能力和命令条目；不加载 JSX/JS。
- `TerminalPluginMarket.install`：独立摘要、来源和默认停用；同一示例由真实 CLI 安装。
- `officeContent`：包内 XML，DOCX 标题/列表/表格；PPTX presentation 关系决定顺序，不获取外部资源。
- `decodeIcon`：ICO DIB 的调色板、行填充、上下倒置、透明蒙版。
- `ShellScreens.attach`：UTF-8 输入拼接、远端全屏 framebuffer 恢复，Ctrl+] 返回宿主。
- `listWslDistributions` / `runWslDistribution`：系统可执行文件、参数数组、取消与子进程回收。

验证脚本与平台限制见 `docs/implementation/stage-05.md`。先运行 user_code，再按上述源码符号调试。
